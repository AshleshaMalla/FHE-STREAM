│  │  │  ├─ Operation: C[i] = A[i]
│  │  │  ├─ Pattern: Binary (read, write)

│  │  │  └─ Memory fence: benchmark::ClobberMemory()
│  │  │
│  │  ├─ Kernel 2: RS_SEQ_SCALE
│  │  │  ├─ Operation: B[i] = scalar × C[i]
│  │  │  ├─ Arithmetic: ModMulFast (fast modular multiplication)
│  │  │  ├─ Bytes: 2 × data_size
│  │  │  └─ (same threading & optimization prevention)
│  │  │
│  │  ├─ Kernel 3: RS_SEQ_ADD
│  │  │  ├─ Operation: C[i] = A[i] + B[i]
│  │  │  ├─ Pattern: Ternary (read two, write one)
│  │  │  ├─ Arithmetic: ModAddFast (fast modular addition)
│  │  │  ├─ Bytes: 3 × data_size
│  │  │  └─ (same threading & optimization prevention)
│  │  │
│  │  ├─ Kernel 4: RS_SEQ_TRIAD
│  │  │  ├─ Operation: A[i] = B[i] + scalar × C[i]
│  │  │  ├─ Pattern: Combined multiply + add (stream triad)
│  │  │  ├─ Bytes: 3 × data_size
│  │  │  └─ (same threading & optimization prevention)

                              DESIGN PATTERNS

┌─ Separation of Concerns ──────────────────────────────────────────────────┐
│                                                                            │
│  Each module has ONE responsibility:                                      │
│                                                                            │
│  ✓ header     → Declare class and interface                              │
│  ✓ fixture    → Manage lifecycle (setup/teardown)                        │
│  ✓ kernels    → Implement benchmark algorithms                           │
│  ✓ main       → Bootstrap framework                                       │
│  ✓ build      → Compile and link                                         │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

┌─ Scalability for Phase 2 ─────────────────────────────────────────────────┐
│                                                                            │
│  To add irregular kernels (Phase 2):                                      │
│                                                                            │
│  1. Create: src/kernels_irregular.cpp                                     │
│  2. Add kernel implementations (GATHER, SCATTER, etc.)                    │
│  3. Register with: BENCHMARK_REGISTER_F(...)->Apply(SchemeArgs)          │
│  4. Update: CMakeLists.txt (add file to add_executable)                  │
│  5. No changes to: fixture.cpp, main.cpp, header.h                        │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

┌─ Critical Code Preserved ─────────────────────────────────────────────────┐
│                                                                            │
│  ✓ Thread Management:                                                     │
│    const int savedThreads = omp_get_max_threads();                       │
│    lbcrypto::OpenFHEParallelControls.SetNumThreads(1);                  │
│    omp_set_num_threads(savedThreads);  // Restore for benchmarks        │
│                                                                            │
│  ✓ NUMA First-Touch:                                                      │
│    #pragma omp parallel for schedule(static)                             │
│    for (size_t i = 0; i < nPolys; ++i) {                               │
│      A[i] = ... (initialized by thread that uses it)                     │
│    }                                                                       │
│                                                                            │
│  ✓ Dead Code Elimination Prevention:                                      │
│    for (size_t j = 0; j < ringDim; ++j) {                              │
│      cTower[j] = aTower[j];  // Compiler can't see this is live         │
│    }                                                                       │
│    benchmark::DoNotOptimize(cTower);  // Tell compiler: this matters!   │
│    benchmark::ClobberMemory();        // Memory fence                     │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

                          BUILD & EXECUTION

Build:
  $ cd fhe-raiderstream
  $ mkdir -p build && cd build
  $ cmake -DCMAKE_BUILD_TYPE=Release ..
  $ make -j

Run Single-Threaded Baseline:
  $ OMP_NUM_THREADS=1 ./fhe_raiderstream --benchmark_filter=RS_SEQ

Run Multi-Threaded (14 cores):
  $ OMP_NUM_THREADS=14 OMP_PROC_BIND=close OMP_PLACES=cores \
    ./fhe_raiderstream --benchmark_filter=RS_SEQ
